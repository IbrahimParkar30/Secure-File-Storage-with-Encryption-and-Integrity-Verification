Smart Contracts

Self-executing rules that automatically enforce policies on every upload and download. Toggle contracts on/off without touching the code.

What are Smart Contracts?

Smart contracts are self-executing programs stored on a blockchain that run automatically when predefined conditions are met — no middleman needed. In this project, contracts enforce security rules (file size, type, expiry, integrity) automatically on every upload and download, just like Ethereum smart contracts enforce financial rules on transactions.

Execution Flow
1

File Selected for Upload

User picks a file and clicks Encrypt & Upload

2

Upload Contracts Fire

SizeLimit → TypeRestriction → MaxUploads run in order. Any failure = rejected.

3

AES-256 Encrypt + Blockchain

File encrypted, hash stored on blockchain

4

Download Requested

User selects a file to download

5

Download Contracts Fire

IntegrityContract → FileExpiryContract. All must pass for decryption to proceed.
